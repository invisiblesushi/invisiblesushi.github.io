## Overview

Autozeek is a digital driving log and fleet telemetry solution designed to track business and personal vehicle usage for tax compliance, mileage verification, and operational efficiency across corporate vehicle fleets.

## Tech Stack

- **Language**: C# 7.0
- **Framework**: .NET Framework 4.6.1, ASP.NET WebForms
- **Data Layer**: Microsoft SQL Server, JSON data structures
- **Integration**: RESTful integration services, HTTP client protocols
- **UI**: HTML, CSS, JavaScript

## Key Engineering Responsibilities

- **Core Application Maintenance & Evolution**: Upgraded legacy modules, resolved defect tickets, and enhanced performance across critical trip-logging workflows.
- **Regulatory Compliance Logic**: Implemented business rules enforcing regional Norwegian tax regulations for commercial vs. private vehicle use classification.
- **External Integration Services**: Integrated RESTful API endpoints for syncing vehicle GPS coordinates, sensor events, and driver status.
- **QA & Testing**: Conducted QA testing, drafted technical specifications, and collaborated in cross-functional Scrum teams to ensure regression-free releases.

## Engineering Takeaways

Maintaining and extending Autozeek strengthened my ability to work effectively with large, established .NET enterprise codebases, refactoring mission-critical logic without disrupting daily business operations.
